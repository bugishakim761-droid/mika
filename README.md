# Kerangka BRIDA Kota Tual

Gunakan empat lapis analisis:
1. Masalah pembangunan.
2. Kebutuhan pengetahuan/bukti.
3. Intervensi riset dan inovasi.
4. Dampak pada indikator pembangunan.

Prioritas analisis dapat mencakup:
- ekonomi biru dan perikanan;
- ketahanan pangan;
- pelayanan publik kepulauan;
- kesehatan bergerak dan telemedicine;
- digitalisasi/SPBE;
- penguatan UMKM dan ekonomi kerakyatan;
- lingkungan pesisir dan laut;
- konektivitas antarpulau.

Setiap prioritas harus memiliki:
masalah → baseline → intervensi → output → outcome → indikator → sumber data → penanggung jawab → waktu.
